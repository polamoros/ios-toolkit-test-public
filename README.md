# ToolkitTest

A minimal iPhone app (`com.polamoros.toolkittest`) scaffolded by the DockAI ios-app toolkit, as a throwaway test of the toolkit.

- `project.yml` is the source of truth; `generate.sh` makes `ToolkitTest.xcodeproj` (never committed).
- CI (`.github/workflows/ios.yml`) compiles on every push — on the public mirror only.
